# Sumant Kumar Portfolio

A modern personal portfolio website built with React, Vite, and Material UI. The site showcases a developer profile, technical skills, featured project work, and contact details for professional networking.

## Overview

This portfolio is designed for a full-stack developer with experience in:

- MERN stack development
- Data Structures and Algorithms in C++
- Python-based data science and analysis
- Responsive front-end design
- Problem-solving and software engineering fundamentals

The app includes multiple route-based pages for Home, About, Skills, Projects, and Contact, all connected through a responsive navigation bar.

## Tech Stack

- React 19
- Vite 7
- Material UI
- React Router
- React Icons
- Styled Components

## Run Locally

1. Open the project folder.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```
